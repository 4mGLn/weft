# Agent Context and Evidence

This directory is the canonical home for agent-facing project context and durable implementation evidence. User-facing operational documentation remains under `docs/`.

| Content | Location |
| --- | --- |
| Current progress and decision ledger | `PROGRESS.md`, `DECISIONS.md` |
| Durable architecture decisions | `decisions/` |
| Phase feasibility evidence | `phase0/` |
| Task records and phase acceptance audits | `tasks/` |
| Temporary evidence and archived plans | `references/`, `archive/` |
| Agent skills | `skills/` |
