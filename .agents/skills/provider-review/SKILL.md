# Provider Review

Review only the requested provider surface. Do not mutate repositories, workspaces, branches, commits, or provider state.

Verify declared provider/version evidence, canonical artifact preservation, stable Weft identifiers, capability discovery, dirty/diverged materializations, exact stack/candidate mapping, changed-target handling, conflict capture, retries, crash ambiguity, external-state reconciliation, and explicit unsupported behavior.

Do not generalize one provider's semantics into the public domain. Return evidence, inference, unknowns, and missing failure-path tests.
